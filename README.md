# 🦅 ClawForge AI v1

**One Request. One Agent System. Real Work.**

ClawForge AI is a local-first AI agent platform powered by a Node.js server and React web interface. It lets you delegate real work to AI agents that can use tools, manage files, run terminals, execute git commands, browse the web, and more.

---

## Quick Start

```bash
# Install
pnpm install

# Copy environment
cp .env.example .env

# Start server (terminal 1)
pnpm server:dev

# Start web (terminal 2)
pnpm web:dev
```

Open http://localhost:5173

## Docker

```bash
docker-compose up -d
```
